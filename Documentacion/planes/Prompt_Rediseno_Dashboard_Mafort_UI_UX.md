# Prompt de Rediseño UI/UX - Dashboard Mafort

Actúa como un Senior Product Designer especializado en CMMS.

Objetivo: rediseñar únicamente la interfaz visual del dashboard, manteniendo toda la funcionalidad existente.

## Objetivos
- Mejorar jerarquía visual.
- Aspecto moderno tipo Centro de Comando.
- Mantener flujo actual.
- No cambiar lógica de negocio.

## Diseño
- Fondo #F4F7FB.
- Tarjetas blancas con sombras suaves.
- Header tipo Centro de Comando con saludo, fecha, operaciones activas y botón 'Ir a Operaciones'.
- KPIs con iconos, tendencias y sparklines.
- Pipeline tipo Kanban.
- Gráfico central de desempeño.
- Alertas accionables.
- Barras de carga de técnicos.
- Timeline de actividad.
- Colores: verde, ámbar, rojo y azul solo para estados.
- Microanimaciones y transiciones suaves.

## Restricciones
- No modificar backend.
- No modificar permisos.
- No crear funcionalidades nuevas.
- Reutilizar componentes existentes.

## Entregables
1. Mockup de alta fidelidad.
2. Nueva estructura visual.
3. Justificación UX.
4. Lista de componentes reutilizados y nuevos.
